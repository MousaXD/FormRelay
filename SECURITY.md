# Security Policy

Please do not open a public issue for a vulnerability that could expose user form data or enable unintended page actions.

Until a dedicated security mailbox is published, use GitHub's private vulnerability reporting feature for this repository if enabled. Include affected version, browser, reproduction steps, impact, and a minimal proof of concept. Do not include real credentials, payment data, private keys, or other third-party secrets.

The current security architecture and threat model are documented in `docs/SECURITY.md`.
