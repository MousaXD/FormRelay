# Contributing to FormRelay

Thanks for helping improve FormRelay. The project is source-available under the repository license, and contributions must remain compatible with that license.

The engineering rules, local commands, trust boundaries, and pull-request expectations are documented in [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md).

Before submitting a change, run:

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Security-sensitive reports should follow [`SECURITY.md`](SECURITY.md), not a public issue.
